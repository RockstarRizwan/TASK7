# 🛒 Basic Sales Summary using SQLite and Python

This is a simple Python project that demonstrates how to connect to a SQLite database, run basic SQL queries, and visualize the results using a bar chart.

## 🔧 Tools Used
- Python
- SQLite (built-in)
- Pandas
- Matplotlib

## 📂 Files
- `sales_data.db`: SQLite database with a sample `sales` table
- `sales_summary.py`: Python script that queries the database and plots a bar chart
- `sales_chart.png`: Output chart showing revenue by product

2. Make sure Python is installed
